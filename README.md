# 가계부 · MoneyBoard

엑셀로 쓰던 가계부를 그대로 옮겨 쓰는 개인 가계부 대시보드예요.
`index.html` 파일 하나로 동작하고, GitHub Pages로 열고, **내 GitHub 비공개 저장소**로 여러 기기를 동기화해요. 다른 서비스 가입은 필요 없어요.

> 이 저장소에는 **코드만** 있어요. 실제 내역은 내 브라우저(localStorage)와, 연결했을 때만 **따로 만든 비공개 저장소**(예: `moneyboard-data`)에 저장돼요.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 한눈에 보기 | 내 현재 자산(월말 추이), 이번 달 지출·수입(위아래로 배치), 이번 달 고정지출 |
| 기간 전환 | 연간 · 월간 · 주간, ‹ › 로 이동, ‘오늘’로 복귀 |
| 이번 달 소비 추이 | 이번 달 누적 지출을 지난달 같은 기간(점선)과 비교, 점마다 금액 표시, 증감액·증감률 |
| 카테고리별 지출 | 도넛 그래프 + TOP 5 목록(비중 %). 분야를 누르면 그 분야 내역으로 이동 |
| 지출의 흐름 | 기간 지출 · 기간 수입 · 수입−지출 · 하루 평균 + **지출 흐름 / 수입 흐름 막대를 위아래로**. 막대를 누르면 그 날(연간은 그 달)로 이동 |
| 최근 일주일 | 7일 합계와 직전 7일 대비 증감, 날짜별 막대, 이번 달 하루 평균 · 주간 평균(7일 환산)과 비교 |
| 기간별 수입·지출 | 올해 · 이번 달 · 이번 주를 색으로 구분해 수입과 지출을 **세로로** 비교 |
| 소비 달력 | 하루 지출 금액 표시, **많이 쓴 날일수록 진한 색**(모든 시안에서 같은 6단계), 오른쪽에 고른 날의 내역. 수입 있는 날·고정지출 예정일 표시. 연간 보기는 12개월 미니 달력 |
| 배치 | 왼쪽 메뉴판(대시보드 · 내역 · 공모주 · 도구) · 가운데 분석 · 오른쪽 내역 입력 보드(최근 입력 포함)와 분야별 추이 비교(버튼으로 최대 4개) |
| 공모주 손익 | 종목별 청약 입금액 · 환불 금액 · 매도 금액 · 청약 수수료 · 이체 수수료 → 손익과 수익률, 총 손익 · 올해 손익 · 진행 중 금액 · 자산 반영액. **출금 · 환불 입금 · 매도 입금 중 고른 것만** 각자의 날짜에 현재 자산에 반영 |
| 고정지출 | 결제일·금액 등록 → 월 총액 / 기록 완료 / 남은 금액, 결제일 지난 항목 한 번에 기록, 자동 기록 옵션 |
| 엑셀 | 불러오기(시트별 합계 검증, 미리보기) · 내보내기(기존 양식과 비슷한 월별 시트) |
| 그 외 | 다크 모드, 모바일 화면(하단 ＋ 버튼으로 입력), JSON 백업/복원, 검색·필터가 있는 내역 보기 |

### 디자인 시안
**디자인** 버튼(팔레트 아이콘)에서 바로 바꿀 수 있어요. 모든 시안이 **말랑 클레이 배치 그대로**이고, 카드 · 버튼 · 메뉴판의 **재질**이 달라요(이 기기에 저장).
주소 끝에 `?design=wood`처럼 붙여서 열 수도 있어요 (`clay` `cloud` `felt` `diary` `wood`).
모든 시안은 밝은 화면이 기본이고, 달 모양 버튼으로 다크 모드를 따로 켜고 꺼요.

| 시안 | 재질과 모양 | 글꼴 | 처음 열 때 받는 양 |
|---|---|---|---|
| 1 · 말랑 클레이 (`clay`, 기본) | 손으로 빚은 듯 볼록한 파스텔 카드 | 나눔스퀘어라운드 | 약 0.8MB |
| 2 · 구름 글래스 (`cloud`) | 하늘빛이 번지는 바탕 위의 반투명 유리 카드 | Pretendard | 약 0.45MB |
| 3 · 펠트 공방 (`felt`) | 바느질 땀이 보이는 펠트 카드, 오트밀 바탕, 세이지 메뉴판 | Noto Sans KR + 고운돋움(제목) | 약 0.55MB |
| 4 · 다꾸 공방 (`diary`) | 모눈종이 바탕, 마스킹테이프로 붙인 종이 카드, 포스트잇 요약(접힌 모서리), 크라프트지 메뉴판, 스티커 버튼, 형광펜 제목 | Pretendard + 주아(제목) | 약 0.7MB |
| 5 · 목공방 (`wood`) | 타공판 벽, 자작나무 합판 카드(아래 옆면 겹 무늬 · 황동 나사), 호두나무 메뉴판, 황동 이름표, 나무 블록 버튼 | IBM Plex Sans KR + Roboto Slab(숫자) | 약 0.4MB |

- 받는 양은 처음 한 번뿐이에요(글꼴은 브라우저에 저장, 앱 파일 약 0.1MB 포함). 고른 시안의 글꼴만 받고, 다른 시안은 처음 고를 때 그 글꼴만 더 받아요.
- 화면이 좁으면(휴대폰) 메뉴가 위·아래로 옮겨 가고, 입력은 아래에서 올라오는 시트로 열려요.
- 없어진 시안(도예 · 자개 · 데님 공방, 젤리 소다 · 피치 선셋, 그 전의 글래스 · 종이 노트 등)을 쓰던 기기는 말랑 클레이로 열려요.

### 공모주 손익
왼쪽 메뉴의 **공모주**에서 관리해요. 종목마다 세 단계와 수수료를 적어요.

| 단계 | 적는 것 | 자산 반영 버튼 |
|---|---|---|
| ① 청약 | 청약일 · **청약 입금액**(청약하려고 넣은 돈) | **출금**: 청약 입금액 + 수수료만큼 자산에서 빠져요(청약일) |
| ② 환불 | 환불일 · **환불 금액**(배정 후 돌려받은 돈) | **환불 입금**(1차 입금): 환불 금액만큼 더해져요(환불일) |
| ③ 매도 | 매도일 · **매도 금액**(팔고 들어온 돈) | **매도 입금**(2차 입금): 매도 금액만큼 더해져요(매도일) |
| 수수료 | **청약 수수료** · **이체 수수료**(계좌 간 이체) | 출금과 함께 빠져요 |

- **손익** = 환불 금액 + 매도 금액 − 청약 입금액 − 청약 수수료 − 이체 수수료. **수익률** = 손익 ÷ 배정 금액(청약 입금액 − 환불 금액)
  - 예: 입금 1,000,000 · 환불 760,000 · 매도 271,000 · 수수료 2,000 + 500 → 손익 **+28,500원** (+11.9%)
- 환불이 먼저 들어오고 매도금이 나중에 들어와도, 고른 흐름이 **각자의 날짜에** 반영돼요.
  - 위 예: 청약일 −1,002,500 → 환불일 +760,000(이때 자산 반영 −242,500) → 매도일 +271,000(최종 +28,500)
  - 앞으로의 날짜로 적은 입금은 그날부터 반영돼요(목록에 ‘○일부터 더 반영돼요’로 보여요).
- 종목마다 반영 합계는 한 줄로 보여요. 예: `A공모주 +28,500원`
- 청약만 했으면 ①만 적고, 목록의 **환불 입력 → 매도 입력** 버튼으로 이어서 채우면 돼요. 아무 버튼도 안 고르면 손익 기록만 하고 자산에는 넣지 않아요.
- 예전 버전에서 적은 기록(청약금액 · 매도금액)은 **청약 입금액 · 매도 금액**으로 그대로 옮겨져요(환불 없음 · 수수료 0). 손익과 자산 숫자는 바뀌지 않아요. 환불이 있었던 종목은 수정에서 환불 금액을 채우면 돼요.
- 대시보드의 ‘내 현재 자산’ 카드에 **공모주 반영** 줄로 합계가 보여요(누르면 공모주 화면으로).
- 손익 색은 증권 앱처럼 이익은 빨강, 손실은 파랑이에요(+/− 부호도 늘 같이 표시).
- 공모주 기록도 GitHub 동기화 · JSON 백업에 함께 들어가고, 엑셀로 내보내면 ‘공모주’ 시트가 따로 생겨요(다섯 금액 · 날짜 · 손익 · 반영 여부, 다시 불러올 때는 건너뜀).

### 내역 입력 규칙
- 금액 앞에 `-` 를 붙이면 **수입**으로 기록돼요(예: `-50000` → 수입 50,000원).
- 내역을 입력하면 분야를 자동으로 골라 줘요. 불러온 내 엑셀 내역에서 브라우저가 스스로 배워요.
- 월급·용돈 분야를 고르면 자동으로 수입 모드로 바뀌어요.

### 분야(카테고리)
엑셀의 카테고리 번호와 같은 번호를 써요.

`1 식비 · 2 카페 · 3 화장품 · 4 교통비 · 5 편의점 · 6 주식 · 7 의류 · 8 선물 · 9 간식거리 · 10 술 · 11 기타 · 12 적금 · 13 용돈 · 14 월급 · 15 미용실 · 16 정기결제`

- 주식·적금은 **재테크**(돈을 옮기는 것)라서 기본적으로 지출·수입 통계에서 빠져요. 상단 ‘재테크 포함’ 스위치나 설정에서 포함할 수 있어요. 현재 자산 계산에는 항상 포함돼요.
- 설정 → 분야에서 이모지·이름·종류를 바꾸거나 새 분야를 추가할 수 있어요.

## 시작하기

1. GitHub에서 새 저장소(예: `MoneyBoard`)를 만들고 **Add file → Upload files**로 `index.html`(과 이 README)을 올려요.
2. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**. 1~2분 뒤 `https://<아이디>.github.io/MoneyBoard/` 에서 열려요.
3. 처음 열면 **엑셀 불러오기** → `2026 가계부.xlsx` 선택 → 미리보기에서 시트별로 “엑셀 합계 일치”를 확인하고 → **가져오기**.
   - ‘현재금액’ 셀이 있으면 그 값에 맞춰 기초자산을 자동으로 계산해 줘요(설정에서 언제든 수정 가능).
4. 여러 기기에서 쓰려면 아래 **GitHub 동기화**를 한 번 설정해요.

## GitHub 동기화 (JSONBin 없이 GitHub만)
가계부 페이지 저장소(공개)와 별도로, **데이터만 담는 비공개 저장소**를 하나 더 만들어 그곳에 저장해요.

1. **데이터 저장소 만들기**: https://github.com/new → 이름 예: `moneyboard-data` → **Private** 선택 → **Add README** 켜기 → Create repository
2. **토큰 만들기**: https://github.com/settings/personal-access-tokens/new
   (Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token)
   - Expiration: 넉넉하게(예: 1년)
   - Repository access: **Only select repositories** → `moneyboard-data`
   - Permissions → Repository permissions → **Contents: Read and write** (Metadata 읽기 권한은 자동으로 붙어요)
   - Generate token → `github_pat_…` 로 시작하는 토큰 복사
3. 가계부 오른쪽 위 **구름 아이콘** → 저장소 `아이디/moneyboard-data`(이름만 적어도 돼요) · 토큰 붙여넣기 → **연결하기**
4. 동기화 창의 **동기화 링크**를 휴대폰 브라우저에서 열면 같은 가계부가 연결돼요.

이렇게 동작해요.
- 비공개 저장소의 `moneyboard.json` 파일 하나에 저장해요. 내역은 날짜순으로 한 줄에 하나라서, 저장소의 **커밋 기록**에서 언제 무엇이 바뀌었는지 볼 수 있어요(자동 백업 겸 변경 기록).
- 입력하면 3초쯤 뒤 자동으로 올라가요(커밋 1개). 바뀐 게 없으면 올리지 않아요. 다른 기기에서 열 때마다 최신 내용을 받아와요.
- 두 기기에서 거의 동시에 올리면, 나중에 올리는 기기가 최신 내용을 다시 받아 합친 뒤 올려요. 내역이 사라지지 않아요.
- **공개 저장소에는 연결되지 않아요.** 공개 저장소(예: 가계부 페이지 저장소)에 내역을 넣으면 누구나 볼 수 있어서 막아 두었어요.
- 토큰이 만료되면 ‘토큰이 올바르지 않거나 만료됐어요’가 떠요 → 새 토큰을 만들고 동기화 창에서 **연결 해제 → 다시 연결** → 다른 기기에서는 새 동기화 링크를 열어요.
- 예전에 JSONBin을 쓰던 기기에서 GitHub에 처음 연결하면, JSONBin에 있던 내역도 **한 번** 가져와서 합쳐요. 그 뒤로는 JSONBin을 쓰지 않아요(예전 `#sync=` 링크는 더 이상 연결되지 않아요).

## 엑셀 양식 (불러오기)
- 월별 시트(`1월`, `2월` …), 머리글 `사용일자 | 카테고리 | 사용금액 | 사용내역 | 불필요`
- 같은 날의 두 번째 줄부터 날짜가 비어 있으면 윗줄 날짜를 이어서 써요. `01월 09일` 같은 글자 날짜도 읽어요.
- 오른쪽 범례 표(`카테고리 | 내역`)로 번호와 이름을 맞춰요.
- `누적금액`, `누적금액(+)` 셀이 있으면 시트별 합계를 검증해서 보여 줘요.
- 같은 파일을 고쳐서 다시 불러오면 중복 없이 최신 내용으로 바뀌어요(앱에서 직접 입력한 내역은 그대로 유지).

## 데이터는 어디에 저장되나요?
- 이 저장소(코드)에는 개인 내역이 들어 있지 않아요. 처음 화면의 ‘예시 데이터’는 무작위로 만든 가상 데이터예요.
- 내역은 브라우저 localStorage에 저장되고, GitHub를 연결하면 **내 비공개 저장소**의 `moneyboard.json`에도 저장돼요.
- 동기화 링크에는 GitHub 토큰이 들어 있어요. 비밀번호처럼 나만 보관하세요. 토큰은 데이터 저장소 하나의 Contents 권한만 있어서 다른 저장소에는 접근할 수 없고, 링크가 새었다면 GitHub에서 토큰을 지우면(Delete) 바로 막혀요.
- 브라우저 데이터를 지우기 전에는 설정 → 데이터 → **JSON 백업 저장**을 해 두면 안전해요.
