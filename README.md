# MoneyBoard

홈페이지: https://imh247.github.io/moneyboard-web/

이 저장소는 홈페이지 코드(index.html)만 공개합니다. 실제 가계부 내역, JSON 백업, 인증 토큰은 이 저장소에 올리지 마세요.

데이터는 브라우저에 저장되며, 앱의 구름 버튼에서 별도의 비공개 GitHub 저장소를 연결해 동기화할 수 있습니다. 기존 비공개 데이터 저장소는 그대로 사용할 수 있습니다.

배포 설정: Settings → Pages → Deploy from a branch → main / (root).
홈페이지를 수정할 때는 이 저장소의 index.html을 갱신하세요.
